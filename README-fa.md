# paribu-mcp 🇹🇷

mcp-name: io.github.mohammad-abbasi-sh/paribu-mcp

سرور MCP غیررسمی و **فقط‌خواندنی** برای **پاریبو** (paribu.com)، بزرگ‌ترین صرافی ارز دیجیتال ترکیه — قیمت‌های زندهٔ ۲۴ ساعته برای ۲۶۶ بازار (بیت‌کوین، اتریوم و بیش از ۱۹۰ کوین در برابر لیر و تتر)، دفتر سفارش با اسپرد و قیمت میانی، معاملات اخیر، فهرست کامل ۴۶۷ بازار و اطلاعات ارزها شامل شبکه‌ها و کارمزدهای برداشت.

> بخشی از پروژهٔ «Turkey MCP factory». وابسته به پاریبو نیست. داده‌ها از API عمومی رسمی پاریبو می‌آیند (`api.paribu.com`، مستندات: `docs.paribu.com/api`) — بدون ورود، بدون کلید API، فقط‌خواندنی.

## برای ایجنت‌های هوش مصنوعی

- **شناسهٔ بازار** به‌صورت حروف کوچک `پایه_مظنه` است، مثلاً `btc_tl` — مظنهٔ لیر ترکیه `tl` نوشته می‌شود، نه `try`.
- **تیکر**: `paribu_get_ticker` با یک بازار، یک خلاصهٔ ۲۴ ساعته برمی‌گرداند؛ بدون بازار، فهرستی رتبه‌بندی‌شده (مرتب‌سازی پیش‌فرض: حجم جفت‌ارز) برمی‌گرداند. تیکر زنده برای ۲۶۶ بازار وجود دارد؛ در پیکربندی ۴۶۷ جفت فهرست شده‌اند (برخی فقط OTC هستند یا هنوز معامله نمی‌شوند).
- **دفتر سفارش**: `paribu_get_orderbook` بهترین قیمت خرید/فروش، اسپرد، قیمت میانی و سطوح را برمی‌گرداند. برای بازار ناشناخته خطا برمی‌گرداند — خود پاریبو در این حالت HTTP 200 با بدنهٔ خالی می‌دهد.
- **معاملات**: `paribu_get_recent_trades` — محدوده ۱ تا ۲۰ (حداکثر API)، از جدیدترین به قدیمی‌ترین.
- **فهرست**: `paribu_list_markets` همهٔ ۴۶۷ جفت را با دقت قیمت/مقدار و گام‌ها فهرست می‌کند؛ `paribu_get_currency` شبکه‌ها، محدودیت‌های واریز/برداشت و کارمزد برداشت هر شبکه را برای یک ارز برمی‌گرداند.
- **پرموسان‌ها**: `paribu_market_movers` بیشترین رشد و افت ۲۴ ساعت اخیر را بر اساس درصد تغییر رتبه‌بندی می‌کند.
- هر پاسخ شامل `fetched_at` (UTC) و `source: api.paribu.com` است.

## نصب

```bash
uvx paribu-mcp
```

یا به پیکربندی کلاینت MCP خود اضافه کنید (مثلاً Claude Desktop):

```json
{
  "mcpServers": {
    "paribu": {
      "command": "uvx",
      "args": ["paribu-mcp"]
    }
  }
}
```

## ابزارها

| ابزار | چه می‌کند |
| --- | --- |
| `paribu_get_ticker` | خلاصهٔ ۲۴ ساعتهٔ یک بازار، یا فهرست رتبه‌بندی‌شدهٔ همهٔ ۲۶۶ بازار (فیلتر `tl`/`usdt`، مرتب‌سازی بر اساس حجم/تغییر/درصد) |
| `paribu_get_orderbook` | دفتر سفارش زنده: بهترین خرید/فروش، اسپرد، قیمت میانی، سطوح (۱ تا ۱۰۰ در هر طرف) |
| `paribu_get_recent_trades` | جدیدترین معاملات عمومی، از جدید به قدیم (۱ تا ۲۰) |
| `paribu_list_markets` | فهرست کامل ۴۶۷ جفت: دقت، گام‌ها، برچسب‌ها، علامت OTC |
| `paribu_get_currency` | اطلاعات ارز: شبکه‌ها، زمان رسیدن، لینک اکسپلورر، کارمزد برداشت، محدودیت‌ها |
| `paribu_market_movers` | بیشترین رشد / افت ۲۴ ساعت اخیر |
| `paribu_health` | آیا API عمومی پاریبو همین حالا در دسترس است؟ |

## نکات

- قیمت‌ها دادهٔ زندهٔ بازار هستند، نه توصیهٔ سرمایه‌گذاری — پیش از هر اقدامی در paribu.com بررسی کنید.
- شناسهٔ بازار ناشناخته در نقطهٔ تیکر HTTP 500 با کد `5001` و در دفتر سفارش HTTP 200 با بدنهٔ خالی برمی‌گرداند.
- نقطهٔ پیکربندی در هر فراخوانی حداکثر یک بار پرسیده می‌شود؛ پاریبو توصیه می‌کند بیشتر از هر ۶۰ ثانیه یک بار پرسیده نشود.
- انتقال با جعل TLS کروم و پشتیبان requests ساده انجام می‌شود؛ درخواست‌ها با فاصلهٔ حدود ۰٫۵ ثانیه ارسال می‌شوند.
